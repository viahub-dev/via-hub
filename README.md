# VIA Hub

**Virtual Intelligent Academy** — Your Way to Learning.

An AI-powered universal learning platform. This repository is currently at
**Stage 0**: a minimal Next.js skeleton used to verify the GitHub → Vercel
deployment pipeline before any product features are built.

## Stack

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- Deployed on Vercel
- Database/Auth: Supabase (added in a later stage)
- AI Provider: Claude, behind a swappable provider abstraction (added in a later stage)

## Status

Stage 0 — project skeleton and deployment pipeline only. No product
features yet.
